# FORGE — Custom PC Builder LandingPage Design in Figma

## Project Overview
FORGE is a fictional custom PC builder landing page designed in Figma. It introduces a platform that helps users plan a PC around their goals, budget, and component compatibility.

## Objective
To create a visually appealing, responsive product landing page using Figma Auto Layout, reusable components, and consistent UI/UX design principles.

## Target Audience
- First-time PC builders
- PC gaming enthusiasts
- Creative professionals and content creators
- Budget-conscious users planning a custom computer

## Main Features
- Header with logo, navigation links, and a call-to-action button
- Hero section with PC imagery and a “Start your build” button
- Three feature cards covering compatibility, budgeting, and guided building
- Three-step “How it works” section
- Starter-build cards with illustrative Indian pricing:
  - The Everyday — ₹74,999
  - The Sweet Spot — ₹1,24,999
  - The Studio — ₹1,84,999
- Compatibility overview and budget tracker design
- Frequently asked questions
- Closing call-to-action section
- Footer with navigation links
- Desktop and mobile layouts

## Design System
- **Primary accent:** Electric lime — #D1FA69
- **Dark surface:** Graphite — #141615
- **Card background:** Dark charcoal — #1D201E
- **Primary text:** Off-white — #F2F3ED
- **Secondary text:** Muted sage — #ADB3A9
- **Typography:** Inter for headings and body text; IBM Plex Mono for technical labels

## Reusable Components
- Primary button with an editable label
- Feature card with editable content
- Starter-build card with editable product details

## UI/UX Concepts
- Figma Auto Layout for sections, headers, cards, and buttons
- Reusable local components
- Shared color and typography styles
- Clear visual hierarchy and consistent spacing
- Responsive desktop and mobile compositions
- Indian currency formatting and GST-related pricing notes

## Design Choices
The dark palette and large PC imagery create a performance-focused identity. Lime accents highlight primary actions, while clear build steps and compatibility guidance make the experience approachable for beginners.
